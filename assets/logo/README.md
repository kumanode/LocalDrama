# Folder Master Logo & Aset Desain

Folder ini digunakan untuk menyimpan file mentah (*master assets*) atau file desain logo aplikasi (LocalMiniDrama).

### File yang Cocok Disimpan di Sini:
- File mentah desain: `.ai`, `.psd`, `.fig`, `.sketch`, atau `.svg` resolusi tinggi
- Varian logo ukuran besar (untuk materi promosi / screenshot)
- Ikon aplikasi desktop (Electron build):
  - Windows: `icon.ico` (256x256 atau multi-size)
  - macOS: `icon.icns` (512x512 / 1024x1024)

> **Catatan:**
> Jika logo sudah siap ditampilkan di web, silakan salin file `.png` / `.svg` ke folder:
> `frontweb/public/logo/` agar langsung dapat dipanggil di antarmuka web.
